مخطط قاعدة البيانات (ERD)

نظام تتبع وجمع بيانات التقديم الجامعي (University Application CRM & Web Scraper)

بيانات الجامعات (Scraped Data)

الجداول المخصصة لجمع وتخزين البيانات من المواقع الخارجية (DAAD وغيرها). تشمل جداول الجامعات (University)، البرامج (Program)، والمتطلبات (Requirement). يتم تحديثها تلقائياً عبر سكريبتات البايثون.

بيانات الطلاب (User CRM)

الجداول المخصصة لإدارة حسابات الطلاب وتتبع تقديمهم. تشمل جداول المستخدمين (User)، طلبات التقديم (Application)، والملفات (Document) التي يرفعها الطالب لكل طلب. 

                erDiagram
                    %% Relationships
                    User ||--o{ Application : "Submits (يقدم)"
                    University ||--o{ Program : "Offers (توفر)"
                    Program ||--o{ Requirement : "Requires (تتطلب)"
                    Program ||--o{ Application : "Receives (تستقبل)"
                    Application ||--o{ Document : "Includes (تحتوي على)"

                    %% User Table
                    User {
                        uuid id PK
                        string name "اسم الطالب"
                        string email "البريد الإلكتروني"
                        string password_hash "كلمة المرور"
                        datetime created_at 
                    }

                    %% University Table
                    University {
                        int id PK
                        string name "اسم الجامعة"
                        string country "الدولة"
                        int ranking "التصنيف"
                        string website_url "الرابط الرسمي"
                        datetime scraped_at "تاريخ آخر تحديث"
                    }

                    %% Program Table
                    Program {
                        int id PK
                        int university_id FK "يرتبط بالجامعة"
                        string title "اسم التخصص (مثل MSc Computer Science)"
                        string degree_level "الدرجة (Master, Bachelor)"
                        string language "لغة التدريس"
                        decimal tuition_fee "الرسوم الدراسية"
                        date deadline "موعد التقديم"
                        string program_url "رابط تفاصيل البرنامج"
                    }

                    %% Requirement Table
                    Requirement {
                        int id PK
                        int program_id FK "يرتبط بالبرنامج"
                        string req_type "نوع الشرط (GPA, IELTS, GRE)"
                        text description "التفاصيل"
                    }

                    %% Application Table (CRM core)
                    Application {
                        int id PK
                        uuid user_id FK "يرتبط بالطالب"
                        int program_id FK "يرتبط بالبرنامج"
                        string status "الحالة: قيد التجهيز، مقبول، مرفوض"
                        date custom_deadline "تاريخ الاستحقاق الشخصي"
                        text notes "ملاحظات الطالب"
                        datetime created_at
                        datetime updated_at
                    }

                    %% Document Table
                    Document {
                        int id PK
                        int application_id FK "يرتبط بطلب التقديم"
                        string file_name "اسم الملف"
                        string doc_type "نوع الملف (CV, Motivation, Passport)"
                        string file_url "مسار تخزين الملف"
                        datetime uploaded_at
                    }

ملاحظة: PK تعني مفتاح أساسي (Primary Key)، و FK تعني مفتاح أجنبي (Foreign Key).
